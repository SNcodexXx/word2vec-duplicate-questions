# Поиск дубликатов вопросов StackOverflow на word2vec

Ранжирование вопросов StackOverflow по смысловой близости: для каждого вопроса нужно поднять его дубликат как можно выше среди кандидатов.

## Подход

- Вектор вопроса считаю как **среднее word2vec-эмбеддингов** его слов
- Кандидатов ранжирую по **косинусной близости** к вопросу
- Метрики ранжирования: **Hits@K** (дубликат попал в топ-K) и **DCG@K** (то же, но со штрафом за низкую позицию)

$$\text{DCG@K} = \frac{1}{N}\sum_{i=1}^{N}\frac{[\text{rank}_i \le K]}{\log_2(1+\text{rank}_i)}$$

## Эксперименты

Сравнил два набора эмбеддингов на 1000 валидационных запросах:
1. Предобученный word2vec на постах StackOverflow ([SO_word2vec](https://github.com/vefstathiou/SO_word2vec))
2. word2vec из `gensim`, обученный на парах вопросов из самой задачи

| Эмбеддинги | Hits@1 | Hits@100 |
|---|---|---|
| Предобученные SO | **0.29** | 0.68 |
| Обученные на задаче | 0.26 | **0.72** |

**Вывод:** предобученные векторы точнее в самом верху выдачи, а свои лучше покрывают длинный хвост: дубликат чаще попадает в топ-100.
